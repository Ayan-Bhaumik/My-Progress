# Answer Guide

Each question number maps directly to the same function/class number in the language solution packs.

Examples:
- Q1 → `q01_pair_with_target_sum` (C), `q01_pairWithTargetSum` (C++), `q01_pair_with_target_sum` (Python)
- Q47 → `q47_kth_largest` / `q47_kthLargest` / `q47_kth_largest`
- Q84 → `LRU`/`q84_LRU`/`q84_LRUCache` implementations

The implementations follow the stated problem constraints where practical. Advanced C solutions use explicit structs and dynamic memory because C has no built-in containers like C++ STL or Python collections.
