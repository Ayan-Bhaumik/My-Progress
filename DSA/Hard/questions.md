# Hard — 30 Questions

## Arrays / Advanced Searching

### 71. Trapping Rain Water
Given bar heights, compute how much water remains trapped after rainfall.

### 72. First Missing Positive
Find the smallest missing positive integer in an unsorted array using O(n) time and O(1) extra space.

### 73. Median of Two Sorted Arrays
Given two sorted arrays, find their combined median in O(log(min(m,n))) time.

### 74. Largest Rectangle in Histogram
Given bar heights in a histogram, find the largest possible rectangular area.

### 75. Maximum Product Subarray
Find the contiguous subarray with the largest product of its values.

### 76. Count Inversions
Count pairs (i, j) where i < j and array[i] > array[j]. Target O(n log n) time.

## Strings

### 77. Minimum Window With Multiplicity Constraints
Find the shortest substring of s that satisfies a multiset of required characters, including duplicate requirements, under a strict linear-time solution.

### 78. Word Break With Reconstruction
Determine whether a string can be segmented into dictionary words and, when possible, return one valid segmentation.

### 79. Regular Expression Matcher
Implement pattern matching where '.' matches any single character and '*' means zero or more repetitions of the preceding element.

### 80. Edit Distance
Return the minimum number of insertions, deletions, and substitutions needed to transform one string into another.

### 81. Longest Palindromic Subsequence
Return the length of the longest subsequence of a string that reads the same forward and backward.

## Linked List / Data Structures

### 82. Merge K Sorted Lists
Merge k sorted linked lists into one sorted linked list efficiently.

### 83. Reverse Nodes in Groups
Given a linked list and integer k, reverse every complete group of k nodes while preserving smaller final groups.

### 84. Design an LRU Cache
Implement a fixed-capacity least-recently-used cache with O(1) average get and put operations.

### 85. Median Finder
Design a structure supporting insertion of numbers and retrieving the median at any time.

## Trees / Advanced Trees

### 86. Serialize and Deserialize Binary Tree
Design algorithms to encode a binary tree into a string and reconstruct the exact same tree.

### 87. Binary Tree Maximum Path Sum
Find the maximum possible sum of values along any non-empty path in a binary tree.

### 88. Recover Swapped BST
Two nodes of a BST were accidentally swapped. Restore the BST using O(1) auxiliary space beyond recursion/iteration requirements.

### 89. Implement a Trie
Build a trie supporting insert, exact search, and prefix search for lowercase English words.

### 90. Word Search II
Given a grid of letters and a dictionary, return all dictionary words that can be formed by adjacent cells without reusing a cell in one word.

## Graphs / Advanced Graphs

### 91. Dijkstra Shortest Paths
Given a weighted directed graph with non-negative edge weights and a source, compute the shortest distance to every vertex.

### 92. Network Delay Time
Given transmission times between directed nodes, determine how long it takes for a signal from one source to reach every node, or report impossibility.

### 93. Minimum Spanning Tree
Given a connected weighted undirected graph, compute the minimum total weight required to connect every vertex.

### 94. Critical Connections
Find all edges in an undirected graph whose removal increases the number of connected components.

### 95. Strongly Connected Components
Partition a directed graph into maximal strongly connected components and return the component assignment for every vertex.

### 96. Alien Dictionary
Given words sorted according to an unknown alphabet, infer a valid ordering of the characters or report that no ordering is possible.

## Dynamic Programming / Backtracking

### 97. Partition Equal Subset Sum
Determine whether an array can be divided into two groups having equal total sum.

### 98. Palindrome Partitioning Minimum Cuts
Split a string into palindromic substrings using the fewest possible cuts.

### 99. N-Queens
Place n queens on an n×n chessboard so that no two queens attack each other, and return the number of valid arrangements and/or the arrangements themselves.

### 100. Burst Balloons
Given balloon values, choose an order to burst them to maximize the total coins earned, where the score for each burst depends on its current neighboring values.
