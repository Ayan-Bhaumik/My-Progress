# Easy — 30 Questions

## Arrays & Hashing

### 1. Pair With Target Sum
Given an integer array and a target value, return the indices of two different elements whose sum equals the target. Assume exactly one valid pair exists.

### 2. Remove Duplicates From Sorted Array
Given a sorted integer array, modify it in place so that each distinct value appears once and return the number of unique values.

### 3. Move Zeroes
Move every zero in an integer array to the end while keeping the relative order of all non-zero elements.

### 4. Maximum Single-Transaction Profit
Given daily prices of a stock, choose one day to buy and a later day to sell so that profit is maximized. Return 0 if no profit is possible.

### 5. Missing Number
An array contains distinct integers from 0 through n with one value missing. Find the missing value.

### 6. Majority Element
Return the value that appears more than n/2 times in an array. Such a value is guaranteed to exist.

## Strings

### 7. Valid Anagram
Given two lowercase strings, determine whether one can be rearranged to form the other.

### 8. First Unique Character
Return the index of the first character in a string that occurs exactly once, or -1 when none exists.

### 9. Reverse Words
Given a sentence containing words separated by spaces, return the sentence with the word order reversed and extra spaces removed.

### 10. Palindrome Check
Determine whether a string is a palindrome after ignoring letter case and non-alphanumeric characters.

## Two Pointers / Searching / Sorting

### 11. Two Sum in Sorted Array
Given a sorted array, find two numbers whose sum equals a target using O(1) extra space.

### 12. Merge Two Sorted Arrays
Merge two sorted integer arrays into one sorted array.

### 13. Binary Search
Implement binary search to return the index of a target in a sorted array, or -1 when absent.

### 14. Search Insert Position
Given a sorted array and a target, return the target index if present; otherwise return the index where it should be inserted.

### 15. Squares of a Sorted Array
Given a nondecreasing array that may contain negative values, return a new array containing all squared values in nondecreasing order.

## Linked List

### 16. Reverse a Linked List
Reverse a singly linked list and return the new head.

### 17. Find Middle Node
Return the middle node of a singly linked list. For an even number of nodes, return the second middle node.

### 18. Detect a Cycle
Determine whether a singly linked list contains a cycle.

### 19. Merge Two Sorted Lists
Merge two sorted singly linked lists into one sorted linked list by reusing the existing nodes.

## Stack / Queue

### 20. Valid Parentheses
Given a string containing (), {}, and [], determine whether the brackets are properly opened and closed in the correct order.

### 21. Implement Stack Using Queues
Design a stack supporting push, pop, top, and empty using only queue operations.

### 22. Implement Queue Using Stacks
Design a FIFO queue using two stacks.

## Trees

### 23. Maximum Depth of Binary Tree
Return the maximum number of nodes from the root to any leaf in a binary tree.

### 24. Inorder Traversal
Return the inorder sequence of a binary tree using an iterative approach.

### 25. Level Order Traversal
Return the node values of a binary tree level by level from top to bottom.

### 26. Search in a BST
Given a binary search tree and a target, return the node containing the target or an empty result if absent.

## Bit / Math

### 27. Count Set Bits
For a non-negative integer, count how many binary digits are equal to 1.

### 28. Power of Two
Determine whether a positive integer is an exact power of two.

### 29. Greatest Common Divisor
Given two non-negative integers, compute their greatest common divisor efficiently.

### 30. Fibonacci Number
Return the nth Fibonacci number using an iterative solution with O(1) extra space.
