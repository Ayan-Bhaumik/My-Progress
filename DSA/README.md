# DSA Practice — 100 Problems

## Goal

Practice data structures and algorithms in LeetCode style, moving from fundamentals to interview-level problems.

## Difficulty split

- Easy: 40
- Medium: 40
- Hard: 20
- Total: 100

## Languages

Every problem contains solutions in:

- **C (C99)** — function-oriented implementation, suitable for a C driver/judge.
- **C++17** — LeetCode-style `Solution`/data-structure implementation.
- **Python 3** — LeetCode-style implementation.

## How to practice

1. Read the problem and examples without opening the solution.
2. Spend 15–30 minutes designing the approach.
3. Write your own solution first.
4. Compare with the provided reasoning and implementation.
5. Run the supplied test cases and add edge cases.
6. Track time and space complexity.

## Recommended order

Start with Easy 1–40, then Medium 1–40, then Hard 1–20. Revisit problems you cannot solve from scratch after 2–3 days.

## Notes

The C/C++ blocks are written as **judge-style function implementations**, not beginner console programs with `main()`. Linked-list and tree questions define the expected node structures where necessary. For problems whose exact C judge signature varies (especially dynamic nested outputs), the implementation is provided as a practice-oriented C API/algorithm.
