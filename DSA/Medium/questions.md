# Medium — 40 Questions

## Arrays / Hashing / Prefix Sum

### 31. Longest Consecutive Sequence
Given an unsorted array of integers, find the length of the longest run of consecutive values in O(n) expected time.

### 32. Product Except Self
For each index, return the product of every array value except the value at that index. Do not use division.

### 33. Subarray Sum Equals K
Count the number of contiguous subarrays whose sum equals a given integer k.

### 34. Top K Frequent Elements
Given an integer array, return the k values with the highest frequencies. The order of the result does not matter.

### 35. Rotate Array
Rotate an array to the right by k positions using O(1) extra space.

### 36. Spiral Matrix
Return all values of an m×n matrix in clockwise spiral order.

### 37. Merge Overlapping Intervals
Given a collection of intervals, merge all intervals that overlap.

### 38. Insert and Merge Interval
Insert a new interval into a sorted, non-overlapping interval list and merge where necessary.

## Strings / Sliding Window

### 39. Longest Substring Without Repeated Characters
Find the length of the longest substring containing no repeated characters.

### 40. Longest Repeating Character Replacement
Given an uppercase string and an integer k, find the longest substring that can be made all one character by replacing at most k positions.

### 41. Permutation in String
Determine whether one string contains a contiguous substring that is a permutation of another string.

### 42. Minimum Window Containing Pattern
Given strings s and t, find the shortest substring of s containing every character of t with required multiplicities.

### 43. Group Shifted Strings
Group strings that belong to the same cyclic-shift pattern, such as "abc" and "bcd".

## Two Pointers / Sorting

### 44. Three Sum
Find all unique triples in an integer array whose values sum to zero.

### 45. Container With Most Water
Choose two array positions to maximize the area formed by the vertical lines and the x-axis.

### 46. Sort Colors
An array contains only 0, 1, and 2. Sort it in one pass with constant extra space.

### 47. Kth Largest Element
Find the kth largest element without fully sorting the array.

## Linked List

### 48. Remove Nth Node From End
Remove the nth node from the end of a singly linked list in one traversal.

### 49. Add Two Numbers
Two linked lists represent non-negative integers in reverse digit order. Return their sum in the same representation.

### 50. Reorder Linked List
Rearrange L0→L1→…→Ln into L0→Ln→L1→Ln-1→… without changing node values.

### 51. Linked List Intersection
Given two singly linked lists, return their first common node, if one exists.

### 52. Copy List With Random Pointer
Clone a linked list where each node has both next and random pointers.

## Stack / Queue / Heap

### 53. Daily Temperatures
For each day, determine how many days must pass before a warmer temperature appears. Return 0 when none exists.

### 54. Evaluate Reverse Polish Notation
Evaluate an arithmetic expression given as tokens in postfix notation.

### 55. Min Stack
Design a stack supporting push, pop, top, and retrieving the minimum value in O(1) time.

### 56. Sliding Window Maximum
For every window of size k in an array, return the maximum value in that window.

### 57. K Closest Points
Given 2D points and an integer k, return the k points closest to the origin.

### 58. Task Scheduler
Given tasks represented by letters and a cooldown interval n, compute the minimum number of time units needed to execute all tasks.

## Trees / BST

### 59. Validate Binary Search Tree
Determine whether a binary tree satisfies strict BST ordering rules.

### 60. Lowest Common Ancestor in BST
Given two nodes in a BST, return their lowest common ancestor.

### 61. Binary Tree Right View
Return the values visible when a binary tree is viewed from the right side.

### 62. Construct Tree From Traversals
Construct a binary tree from its preorder and inorder traversal sequences.

### 63. Diameter of Binary Tree
Return the length of the longest path between any two nodes in a binary tree.

### 64. Kth Smallest in BST
Find the kth smallest value in a binary search tree.

## Graphs

### 65. Number of Islands
Given a grid of land and water cells, count the number of connected islands using 4-directional adjacency.

### 66. Clone Graph
Deep-copy an undirected connected graph where each node stores a list of neighbors.

### 67. Course Schedule
Given course prerequisites, determine whether it is possible to finish all courses.

### 68. Shortest Path in Unweighted Graph
Given an unweighted graph and two vertices, return the shortest number of edges between them or -1 if unreachable.

### 69. Rotting Oranges
In a grid, rotten cells infect adjacent fresh cells each minute. Return the number of minutes until no fresh cells remain, or -1 if impossible.

### 70. Pacific-Atlantic Water Flow
Find all grid cells from which water can flow to both the top/left ocean and the bottom/right ocean under non-increasing movement rules.
